# Testes End-to-End (E2E) — Topic Log

Pasta destinada aos testes E2E e de acessibilidade automatizada (WCAG 2.2 AA), cobrindo as jornadas críticas em modo sandbox:
- Cadastro e navegação sem KYC concluído;
- Bloqueio de contratação sem KYC bilateral válido;
- Publicação de encomenda respeitando limites de 5 kg (bicicleta) e 20 kg (moto/carro);
- Aceite único e congelamento de comissão (13% gratuito / 7% Premium);
- Checkout com preço idêntico entre modalidades e aviso ao desativar método;
- Confirmação de entrega exigindo código válido + foto privada (ou revisão de exceção).
